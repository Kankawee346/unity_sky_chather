# CYBER//DIVE — ต้นแบบ 2.5D

เกมใหม่แยกจาก CatchLab เปิดด้วย Unity **6000.5.2f1**, Universal 3D URP **17.5.0** ภารกิจคีย์บอร์ดกำหนดเวลาสูงสุด 120 วินาที: Approach (0–20s), Firewall (20–60s), Warden (60s เป็นต้นไป) ยานยิงอัตโนมัติ หลบโดรนและกระสุน สะท้อนกระสุนสีฟ้าเพื่อเพิ่ม SYNC และ Overdrive ทำลาย WARDEN CORE ก่อนเวลาหมด บอสโจมตีถี่ขึ้นเมื่อพลังเหลือครึ่งหนึ่ง และบันทึก BEST ในเครื่องเมื่อจบรอบ

## เปิดเล่น

เปิดโฟลเดอร์ `CyberDive` ใน Unity Hub แล้วเปิด `Assets/CyberDive/Scenes/Dive.unity` กด Play จากนั้นคลิก Begin Breach หรือ Enter

| ปุ่ม | หน้าที่ |
| --- | --- |
| A/D หรือลูกศร | เลื่อนยานซ้าย/ขวา |
| Space | เปิดโล่ 0.6 วินาที คูลดาวน์ 2 วินาที |
| Escape | หยุด/เล่นต่อ |
| Enter | เริ่มรอบ/ลองใหม่ |
| M | เปิด/ปิดเสียง |
| F1 | ลดเอฟเฟกต์ดาว |
| F2 | เปิด/ปิดกล้องสั่น |
| F3 | เปิด/ปิดแสงตอบสนองเบา ๆ (เริ่มต้นปิด) |

ค่าเริ่มต้นคือ KEYBOARD และไม่เชื่อมเครือข่าย คลิกปุ่ม INPUT บนเมนูเพื่อวน KEYBOARD → ESP32 JOYSTICK + PI → ESP32 FSR + PI เมื่อต้องการต่ออุปกรณ์จริง กระสุนฟ้าสะท้อนได้ด้วยโล่ กระสุนขาวและโดรนต้องหลบ HULL หมดแพ้ กำจัดบอสก่อน 120 วินาทีชนะ

เมนู DIFFICULTY วน Easy → Normal → Hard เลือกก่อนเริ่มรอบหรือหลังจบรอบ ระหว่างเล่นและพักเกมจะล็อกไว้ ความยากเปลี่ยนความเร็วกระสุนศัตรู/โดรนและความถี่ของชุดกระสุน โดย Normal ใช้ค่าเดิม เกมจำระดับความยาก เสียง เอฟเฟกต์ กล้องสั่น และแสงตอบสนองเมื่อเปิดใหม่ แต่เริ่มด้วยคีย์บอร์ดทุกครั้ง BEST ALL คือคะแนนสูงสุดรวมทุกระดับ ปุ่มเมนูใช้เมาส์ ส่วน Enter ใช้เริ่มเกมเท่านั้น

| ระดับ | ความเร็วศัตรูเทียบ Normal | ชุดกระสุนปกติ / บอสโกรธ |
| --- | --- | --- |
| Easy | 80% | ทุก 8 / 6 จังหวะ |
| Normal | 100% | ทุก 6 / 4 จังหวะ |
| Hard | 120% | ทุก 4 / 3 จังหวะ |

จังหวะละ 0.5 วินาที ความยากไม่เปลี่ยน HULL เวลา 120 วินาที พลังบอส อัตรายิงยาน หรือคูลดาวน์โล่ ยังต้องปรับสมดุลเพิ่มเติมจากการเล่นของคนจริง

## สร้างเกม Windows

เวอร์ชันตัวเลือกผู้เล่นอยู่ `Build/Options/CyberDive.exe` เพิ่มระดับความยาก ปุ่มเสียง และการจำค่า เก็บทั้งโฟลเดอร์ Options เมื่อนำไปเปิดเครื่องอื่น

เวอร์ชัน Campaign ที่จัดไว้ให้ลองอยู่ `Build/Campaign/CyberDive.exe` ส่วน `Build/Windows` คือ executable ต้นแบบรอบก่อน ภาพจากภารกิจใหม่อยู่ `Screenshots/cyber-dive-campaign-1080p.png`

เวอร์ชันปรับงานภาพล่าสุดอยู่ `Build/Polished/CyberDive.exe`: ยานเพิ่มส่วนเกราะและเครื่องยนต์ บอสแกนเหลี่ยมพร้อมส่วนประกอบรอบวง โดรนรูปทรงใหม่ เส้นนำทางในฉาก และเอฟเฟกต์กระแทก/ทำลายแบบใช้วัตถุซ้ำ เอฟเฟกต์ภาพไม่เพิ่มความเสียหายหรือเปลี่ยนกติกา ภาพจริงอยู่ `Screenshots/cyber-dive-polished-1080p.png`

ออกจาก Play Mode แล้วเลือก `CYBER DIVE > Build Windows Player` ผลอยู่ `Build/Windows/CyberDive.exe` ต้องเก็บทั้งโฟลเดอร์ Windows รวมไฟล์ Data และ UnityPlayer.dll จึงเปิดเล่นได้

ถ้าต้องสร้างฉากใหม่ ใช้ `CYBER DIVE > Create or Reset Dive Scene` กับฉากต้นแบบนี้เท่านั้น เมนูนี้สร้างฉากใหม่จากโค้ด อย่าใช้ขณะที่มีฉากที่แก้เองแล้วยังไม่บันทึก

## อุปกรณ์และเพื่อนฝั่งกล้อง

คู่มือและรูปแบบข้อมูลอยู่ `../CyberDiveBridge/PROTOCOL_TH.md` ตัว Bridge ใหม่รับ MQTT เดิมจาก ESP32 และ pose จาก Pi เปิดเฉพาะตัวใหม่หรือเก่าอย่างใดอย่างหนึ่ง เพราะพอร์ตชนกัน

เริ่มจากทดสอบ `tools/pose-simulator.py` ก่อน แล้วเพื่อนแทนส่วนจำลองด้วยผลกล้องจริง ระบบไม่ต้องส่งวิดีโอและไม่ต้องติดตั้งโมเดล AI บนคอมเกม

## แพ็กเกจ / งานภาพ

ติดตั้ง Cinemachine 3.1.7, ProBuilder 6.1.4, VFX Graph 17.5.0 ในโปรเจกต์ใหม่นี้แล้ว ใช้ Cinemachine Flight Rig, โมเดลเรขาคณิต, จุดบนผิว, dither shader และ VFX Graph สำหรับ Parry burst งานฉาก โมเดล และเอฟเฟกต์ขั้นละเอียดเป็นงานปรับภาพรอบถัดไป ไม่ควรถือว่าภาพตรงคอนเซปต์ขั้นสุดท้ายแล้ว

เสียงต้นแบบสังเคราะห์จากโค้ดเอง ฟอนต์ IBM Plex Mono มาจาก Google Fonts และมี OFL ใน `Assets/CyberDive/Art/Resources/FONT-LICENSE.txt`

## ตรวจสอบ

- EditMode: `CyberDive.Tests` ตรวจ HULL, damage immunity, parry cooldown, pause, score และการ re-arm ท่าทาง
- PlayMode: `CYBER DIVE > Run Gameplay Tests` ตรวจเวลารอบ กระสุน การชน การสะท้อน restart และอินพุตหมดอายุ รายงานล่าสุดจากเมนูอยู่ `../docs/superpowers/plans/cyber-dive-latest-tests.xml`; สำเนาผลที่ตรวจผ่านอยู่ `cyber-dive-play-final.xml` และ `cyber-dive-rules-final.xml` ในโฟลเดอร์เดียวกัน
- Bridge: ที่ `CyberDiveBridge` รัน `npm.cmd test` มีการส่ง MQTT ผ่าน localhost จริงและอ่าน HTTP ไม่ใช้บริการตัวเก่า

การทดสอบกับ ESP32 + Camera 3 ของจริงและการชดเชยความหน่วงต้องทำกับอุปกรณ์หน้างาน ข้อมูลเกินอายุหยุดการควบคุมและไม่สะสมคำสั่งไว้ใช้ภายหลัง

ภาพจากเกมจริงอยู่ `Screenshots/cyber-dive-live-1080p.png` กด F12 ในเกมเพื่อบันทึก `preview.png` ในโฟลเดอร์ที่มี executable ของเวอร์ชันนั้น

CLI บนเครื่องอัปเดตเป็น 1.0.0 ตามที่อนุมัติแล้ว `Assets/CyberDive/Editor/PipelineCompatibility.cs` เป็นตัวแก้เฉพาะ Editor สำหรับการประกาศตำแหน่งของ Pipeline บน Unity 6.5 จนกว่าต้นทางจะแก้ ไม่รวมใน Windows player
