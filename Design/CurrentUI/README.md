# Current CatchLab UI

ไฟล์ `CatchLabUI.cs.txt` และไฟล์ตัวช่วยอีกสามไฟล์เป็นสำเนา source ของ UI pixel knight ปัจจุบันหลังถอดสกิลออก พร้อมรูปและฟอนต์ใน `Art/`. ใช้เก็บเวอร์ชันนี้เมื่อรับ ZIP UI ของเพื่อนในภายหลัง โค้ดที่ Unity ใช้งานจริงอยู่ใน `CatchLab/Assets/`. นามสกุล `.txt` ป้องกัน Unity คอมไพล์คลาสซ้ำ.

`CatchLab-Original-Source.zip` เก็บโปรเจกต์ Unity ต้นฉบับที่เปิดกลับได้ (Assets, Packages, ProjectSettings และ README) โดยไม่รวมไฟล์แคชขนาดใหญ่หรือข้อมูลลับของ Bridge.

เมื่อรวม UI ใหม่ ให้เก็บชุดเดิมและแยกเวอร์ชันใหม่ออกจากกัน ฟังก์ชันปุ่มเลือกระดับ, FSR, Joystick, เริ่มเกม, พักเกม, ประวัติผล และการบันทึกผลต้องยังทำงานเหมือนเดิม.
