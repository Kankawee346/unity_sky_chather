# ตรวจชุด UI/เกมจาก ProjectSettings.zip เทียบใบเกณฑ์

ตรวจจากไฟล์ใน ZIP วันที่ 11 พ.ย. 2569 เท่านั้น ยังไม่ได้เปิด Play หรือสร้าง Web Build ของชุดนี้ และยังไม่ได้เปลี่ยนโปรเจกต์ CatchLab ที่ใช้งานอยู่

## จุดแข็งที่นำมาใช้ได้

- มีหน้า Start, Pause, Game Over, HUD, ชื่อผู้เล่น และ ranking ในฉาก `Assets/Scenes/SampleScene.unity`
- มี 3 ฉากหลัง Sky / Space / Night Sky เปลี่ยนได้จากเมนู, ภาพพิกเซล, เสียงปุ่ม และเอฟเฟกต์
- เมนู Easy / Normal / Hard เปลี่ยนอัตราการเกิดและความเร็วตกตาม `Assets/Script/SpawnManager.cs`

## ต้องแก้เพื่อรักษาคะแนนส่วนชิ้นงาน 20 คะแนน

1. **ต่อเซนเซอร์และ MQTT**: `Assets/Script/PlayerController.cs` ใช้คีย์บอร์ดเท่านั้น และเมนูไม่มีโหมด FSR/Joystick; `PauseMenuController.cs` ยังใช้ A/D และกดพร้อมกันเพื่อยืนยัน ต้องเชื่อม Bridge/ESP32-S3 เดิมและแยกโหมด FSR 2 ตัวกับจอย 1 ตัว โดยคงพฤติกรรมการกดปุ่มเดิมของ CatchLab
2. **ส่ง Firebase จริง**: `GameManager.EndSession()` เพียงสร้าง JSON และมี TODO; `Leaderboard.cs` เก็บใน PlayerPrefs บนเครื่อง ต้องส่ง user, score, time, level, playCount ไป Firebase และอ่านผลวิเคราะห์ให้ตรวจได้
3. **แก้ Combo ตามใบเกณฑ์**: `GetStreakMessage` ชมที่ 5/10/15/20; เกณฑ์ต้องชมเมื่อรับต่อเนื่อง 2/3/4/5 ครั้ง
4. **ระดับที่บันทึกต้องตรงกับที่เล่น**: `GameManager.level` เริ่ม 1 และไม่พบโค้ดแก้ค่าเมื่อเลือก Easy/Normal/Hard; เกมเปลี่ยน `complexity` แต่ JSON จะส่ง level 1 เสมอ
5. **ปรับจำนวน/มูลค่าของตก**: ในแต่ละแผนที่มี prefab 4 ตัว (reward 2, fuel 1, obstacle 1) ส่วน fuel ให้ 0 คะแนน; ใบเกณฑ์ระบุของตก 1–3 แบบและคะแนนต่างกัน ควรกำหนด 3 ชนิดที่รับแล้วได้คะแนนต่างกันให้ชัด หรือยืนยันกับอาจารย์ว่าสิ่งกีดขวางไม่นับเป็นชนิดของตก
6. **ตรวจความยากและ WebGL จริง**: ตอนนี้ Easy/Normal/Hard ปรับอัตราเกิด/ความเร็ว/ขนาดสิ่งกีดขวาง แต่เส้นทางตกไม่มีรูปแบบต่างชัดเจน; ควรทดสอบว่าไล่จากคาดเดาง่ายไปยาก และสร้าง Web Build เล่นจริง

## ความเข้ากันได้/งานส่ง

- ZIP ใช้ Unity 6000.6.2f1 ขณะที่ CatchLab เดิมใช้ 6000.5.2f1; Package manifest ต่างกันมาก จึงไม่ควรคัดลอก `ProjectSettings`/`Packages` ไปทับของเดิมตรง ๆ
- ฉาก Canvas ใช้ Constant Pixel Size; ต้องตรวจหน้าจอเว็บหลายขนาดว่าปุ่มและข้อความไม่หลุดกรอบ
- ZIP ไม่มีคู่มือการติดตั้ง/ใช้งาน และไม่มี Web Build; ส่วน Code 5 คะแนนต้องจัดชุด source, library และขั้นตอนให้ครบ
- ยังต้องสาธิต ESP32/เซนเซอร์จริง, Firebase จริง, โปสเตอร์ A1 และคลิปแนวตั้ง FHD 60 FPS ไม่เกิน 3 นาที

แนวทางรวมงาน: เก็บ CatchLab เดิมไว้เป็นต้นฉบับ แล้วสร้างเวอร์ชันเพื่อนแยก ใช้ภาพ/ฉาก/ปุ่มจาก ZIP และต่อเข้ากับระบบเซนเซอร์ MQTT, Firebase และกติกาที่ผ่านการทดสอบของ CatchLab เดิม.
